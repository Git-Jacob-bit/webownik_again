# Security policy

Do not report vulnerabilities through public application feedback or a public GitHub issue.
Use GitHub's private vulnerability reporting page:

https://github.com/Git-Jacob-bit/webownik_again/security/advisories/new

Include reproduction steps, affected endpoint or component, and the expected impact. Do not include
real user data, passwords, session cookies, API keys, or other secrets. Security fixes are provided
for the current deployed version of Webownik.
